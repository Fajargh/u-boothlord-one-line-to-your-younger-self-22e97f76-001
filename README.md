A single line to send back to my younger self — if one line were all I got. No explanation, no context, no second sentence. One breath, one sting, one image that stays: the rent money was never in the job that never called back, it was in the code written at 2 a.m. on a cheap laptop.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```

`main.py` writes the entry line to `/output/entry.txt` (one line, under 200 characters).
